# Estufa Tecnológica da Mata Atlântica

## Sobre o projeto

Este projeto foi desenvolvido como proposta de conclusão de curso com o objetivo de unir tecnologia, sustentabilidade e desenvolvimento econômico local.

A cidade de Cruzeiro possui uma linha de trem turístico que passa por áreas de vegetação da Mata Atlântica. Pensando nisso, desenvolvemos a ideia de uma estufa tecnológica instalada na linha do trem.

O trem passaria pelo interior da estufa, permitindo que os visitantes observem espécies nativas da Mata Atlântica enquanto aprendem sobre a importância da preservação ambiental.

## Objetivos

- Conscientizar a população sobre a preservação da Mata Atlântica
- Incentivar o turismo na cidade de Cruzeiro
- Estimular o comércio local
- Utilizar tecnologia para monitoramento ambiental

## Tecnologias utilizadas

- Arduino
- Sensores de umidade do ar e do solo
- Sistema de irrigação automática
- API de previsão do tempo
- Aplicativo para monitoramento das condições ambientais
- ASP para integração do sistema

## Funcionamento do sistema

O sistema contará com sensores que monitoram:

- Umidade do ar
- Umidade do solo
- Temperatura

Com base nesses dados:

- A irrigação será ativada automaticamente quando necessário
- Um reservatório de água será abastecido quando houver previsão de chuva
- Todas as informações serão exibidas em um aplicativo para os responsáveis pela estufa

## Impacto esperado

- Aumento do turismo local
- Incentivo ao comércio da cidade
- Educação ambiental
- Preservação da biodiversidade da Mata Atlântica
